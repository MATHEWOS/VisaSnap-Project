VisaSnap mobile web app

Open index.html in a browser, or host this folder with any static web server.
For installable PWA behavior and offline caching, serve the folder from localhost or HTTPS.

Features:
- Take a new photo with a phone camera.
- Upload an existing image from phone storage.
- Crop and position the image into common passport/e-visa photo sizes.
- Download a JPG passport-style image.
- Search curated official e-visa and immigration application links by destination country.
- Install VisaSnap to a mobile or desktop home screen.
- Use the core photo tool offline after the first successful load.

Important:
Visa and passport photo rules change by country and date. Always confirm current photo size, background, file size, eligibility, and fees on the official destination government website before submitting an application.
