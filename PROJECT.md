# VisaSnap Project

VisaSnap is a mobile-first passport and e-visa photo helper.

## Current App

- `index.html` - mobile web app shell.
- `styles.css` - responsive app styling.
- `app.js` - camera/upload, crop/export, and e-visa link finder logic.
- `README.txt` - quick user instructions.

## Features

- Take a new photo from a phone camera.
- Upload a photo from phone storage.
- Crop and position a passport-style image.
- Export JPG files in common e-visa/passport dimensions.
- Search curated official e-visa and immigration links by destination country.
